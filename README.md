# سيرة ذاتية منسّقة

## التقنيات

HTML وCSS داخل الصفحة.

## فكرة المشروع

تطبيق تنسيق السيرة الذاتية والجداول والصورة وروابط التواصل.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `index.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `index.html`

## حدود المشروع

المشروع صفحة ثابتة، ولا يحتاج قاعدة بيانات.
